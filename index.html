Personal backup integration

A recoverable copy of a personal Digital Familiar.

Digital Familiar Backups is an owner-operated application that encrypts a local backup and stores the encrypted file in the owner's Google Drive account.

What the application does

Digital Familiar is a personal record and assistant system. Its backup integration protects a snapshot of the installation's stored records, application configuration, and recovery files.

  1. A local backup is prepared on the owner's computer.
  2. The backup is encrypted on that computer using the owner's recovery-key recipient.
  3. The encrypted file is uploaded to the owner's Google Drive. A downloaded copy is checked against the original encrypted file before the upload is reported as verified.

The owner can separately run a recovery rehearsal with their saved private recovery key. A successful upload and a successful recovery rehearsal are separate checks.

Google Drive access

The integration uses Google authorization with the drive.file permission. This allows access to files created by, or specifically made available to, the application. It uses that access to create backup folders, upload encrypted archives, and read those archives for verification and recovery.

The application is for the operator's personal installation. The owner authorizes their own Google account during local setup. This information site has no sign-in form or backup upload feature.

Owner control

The owner chooses the destination account, keeps the recovery key separately, controls how long backups are retained, and can stop uploads or revoke Google access. The privacy policy explains the data handled by this integration. The terms of use describe its personal-use scope.

Contact

For questions about this installation, use the user support email listed in its Google authorization screen. The Google Cloud project owner maintains that address and this application.
